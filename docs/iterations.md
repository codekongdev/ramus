# 구현 반영 기록

개발 원본 `ramus`에서 검증한 구현을 이 저장소에 단계적으로 반영한다. 원본 저장소의 과거 검증과 이 저장소에서 실행한 결과를 구분한다.

| 단위 | 범위 | 상태 | 담당·파일 소유권 |
| --- | --- | --- | --- |
| U08 | 1단계: 서버 실행 기반·로그인·공동 대화 | 검증됨 | 구현자: `apps/api/`; 통합 담당: 설정·스크립트·계약·생성 타입·문서 |

이번 완료 조건: 명시적 DB 이관/seed, 두 사용자 세션, 서버 작성자·메시지 순서, 권한·세션 만료·중복 요청 경계, 재시작 후 영속성, 실제 API와 OpenAPI/생성 타입 일치.

기능 반영 순서는 공동 대화 → 분기·선택 참고·실제 AI → 자동 기억 → 문서 수정안·적용 → 웹 통합이다. 이번에는 M01·M08의 공동 대화 부분과 A01·A11의 해당 부분만 검증한다. 전체 P0와 A01~A12 완료를 뜻하지 않는다.

원본 참고: `4bfee18`의 기반 구현과 현재 구현의 세션·재시도 권한 경계. 미래 기능용 스키마·DTO·어댑터는 이번 반영에서 제외한다. 초기 migration도 7개 테이블로 축소한 별도 이력이므로, 이후 원본 migration을 통째로 덮어쓰지 않고 이 저장소의 현재 스키마를 기준으로 후속 migration을 작성한다.

## U08 실행 결과 (2026-11-09)

`pnpm bootstrap:api`와 `pnpm verify --postgres`를 실행했다. Ruff, Domain Unit 3개, 서버 Integration·입력·계약·migration 27개, 생성 타입 검사가 통과했다. 별도 PostgreSQL 17에서 독립한 두 HTTP 세션·동일 요청의 동시 전송·서버 재시작 후 메시지와 세션 복원도 확인했다. [실행 근거](verification/U08-step1.json)를 보존한다.

독립 검수에서 발견한 DB 저장 불가 문자열(NUL·잘못된 UTF-8)의 입력 경계를 보완했고 회귀 테스트와 재검수를 통과했다. 멤버십 취소 후 메시지·프로젝트 생성 영수증의 재조회도 차단한다. TestClient의 httpx 폐기 예정 경고는 남지만 테스트 실패는 없다.

실제 모델 호출·비용은 0이다. 웹 화면·브라우저 시험·전체 P0 수용 검증은 이번에 실행하지 않았다. 사용자 재사용 결과는 미확인이며 다음 반영은 별도 요청으로 진행한다.
